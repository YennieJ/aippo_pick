# 📱 스크린샷 6컷 (실제 노출 순서)

> 공통 레이아웃: **상단 30% = 카피 영역 / 하단 70% = 디바이스 목업**
> `[노랑]` = 옐로우 하이라이트 키워드, `[배지]` = 옐로우 배경+검정 글씨 배지

## 1️⃣ 캘린더 + 증권사 필터  ← 유일 차별점

> ⚠️ **실제 위치 정정:** 증권사 필터는 **홈이 아니라 캘린더 화면**에만 있음. 캘린더 우상단 **필터 아이콘** → **바텀시트 모달**에서 **체크박스로 증권사 선택** → 파란 `적용`(#4A90E2) 버튼. 적용되면 필터 아이콘이 파란색으로 바뀌고 캘린더에 해당 증권사 종목만 남음. (홈엔 필터 UI 없음)

**카피**
- 메인: **[노랑:내 증권사]로<br>청약 가능한 공모주만**
- 서브: 증권사만 골라두면 캘린더에 그 종목만 쏙

**더미 데이터:** 필터 모달에서 `미래에셋·키움` 체크 → 적용

**와이어프레임 (캘린더 + 필터 바텀시트 열린 상태)**
```
┌─────────────────────────┐
│   내 증권사로            │ ← 메인카피(흰색, '내 증권사'만 노랑)
│   청약 가능한 공모주만   │
│                         │
│  ┌───────────────────┐  │
│  │ 9:41    ▮▮▮ 🔋100% │  │
│  │ 공모주 캘린더   [⚙]│  │ ← 우상단 필터 아이콘(파란=활성)
│  │ ●청약 ●환불 ●상장  │  │ ← 이벤트 타입(실제 3종)
│  │ ── 2026년 6월 ──   │  │
│  │ 일 월 화 수 목 금 토│  │
│  │     1  2  3  4 5• 6 │  │ ← 점=이벤트(파랑/초록/빨강)
│  │  7 8• 9 10 11•12 13 │  │
│  │ ╔═══════════════╗   │  │ ← 바텀시트 모달
│  │ ║ 증권사 선택     ║   │  │
│  │ ║ 미래에셋증권 [✓]║   │  │ ← 체크박스(파랑)
│  │ ║ 키움증권     [✓]║   │  │
│  │ ║ 삼성증권     [ ]║   │  │
│  │ ║ NH투자증권   [ ]║   │  │
│  │ ║  [   적용   ]   ║   │  │ ← 파란 버튼 #4A90E2
│  │ ╚═══════════════╝   │  │
│  └───────────────────┘  │
└─────────────────────────┘
```

**카피**
- 메인: **청약일·환급일<br>[노랑:알림]으로 놓치지 않게**
- 서브: D-Day 알림 · 스펙/리츠 필터

**와이어프레임 (잠금화면 + 캘린더 split)**

## 📋 캡처 직전 체크리스트
1. 시뮬레이터 부팅 → 앱 실행
2. **집중 모드 ON** (배너 차단)
3. 상태바 고정:
   ```bash
   xcrun simctl status_bar booted override --time "9:41" \
     --batteryState charged --batteryLevel 100 --cellularBars 4 --wifiBars 3 --operatorName ""
   ```
4. 컷별 데이터 세팅 (필터 선택 / 즐겨찾기 / 일지 입력 / AI 리포트 열기)
5. 4컷은 `xcrun simctl push`로 알림 발송 후 잠금화면 캡처
6. 캡처 → 피그마에서 카피·병아리·배지 합성

> ⚠️ 일지(5컷)·즐겨찾기(6컷)는 빈 계정이면 텅 빔 → **시드 데이터 필요**. 코드에 스크린샷용 mock 주입할지 검토 예정.
