# 알림 설정 — 5개 개별 On/Off + 전면 인라인 UX 재구성

## Context

알림을 종류별(5종)로 개별 On/Off 하도록 확장하면서, 기존 "하이브리드"(토글은 인라인, 상세는 바텀시트 모달) UX를 재검토한 결과 **부적합** 판정:

- **시간을 바꿀 수 있는 유일한 알림(오늘 공모주 일정)인데, `alarmTime` 컨트롤이 그 토글에서 분리돼 "상세 설정" 모달에 숨어 있다** → 소속 불명확·발견성 낮음.
- 모달이 성격 다른 설정(오늘 일정 전용 시각·SPAC/REITs + 전역 증권사 필터)을 뭉쳐 놓음.
- 토글=인라인 즉시저장 / 시각·SPAC·증권사=모달 "적용" 저장 → 상호작용 모델 이원화.

**결정(사용자):** 전면 인라인 재구성. 사용자가 처음 그린 ASCII 목업 방향과 동일 — 시각·SPAC/REITs를 "오늘 공모주 일정" 아래 인라인 확장, 증권사는 별도 "필터 설정" 섹션. 시각·증권사는 요약 행 탭 → 컴팩트 시트. 큰 모달 제거, 저장은 전부 즉시(시트는 "완료" 시 1회).

백엔드 계약: `GET /notification_setting/:deviceId`, `PUT /notification_setting`(바뀐 필드만 보내도 나머지 유지). 5개 boolean 필드는 백엔드 지원·라운드트립 확인 완료.

## 이미 반영된 데이터 레이어 (working tree — 유지)

아래는 이번 세션에 이미 구현·에뮬레이터 검증됨. 재구성에도 그대로 유효:
- `notification.types.ts` — 3개 타입에 `notifyMorning/notifySubStart/notifySubEnd/notifyAiReport/notifyWeekly`(boolean) 추가.

**이번 재구성으로 조정:** `applyNotificationSettings`(모달 배치 저장)와 `tempNotifySpac/tempNotifyReits`는 제거(아래 참조).

## 목표 레이아웃 (전면 인라인)

```
알림 설정
─────────────────────────────
전체 알림                        [토글]   ← notifyAll (OFF면 아래 전체 회색·비활성)

─── 알림 종류 ────────────────
오늘 공모주 일정                 [토글]   ← notifyMorning
   (notifyMorning ON일 때만 아래 노출)
   알림 시각            오전 8:00  [>]    ← 탭 → 시간 시트
   포함 종목      [✓ SPAC] [✓ REITs]     ← 인라인 체크박스, 즉시 저장
청약 시작 알림                   [토글]   ← notifySubStart   매일 오전 10:00 자동
청약 마감 알림                   [토글]   ← notifySubEnd     매일 오후 3:30 자동
AI 리포트 완성                   [토글]   ← notifyAiReport   조건 충족 시 오전 8:50 자동
이번 주 요약                     [토글]   ← notifyWeekly     매주 일요일 오후 8:30 자동

─── 필터 설정 ────────────────
증권사                전체 / N개  [>]     ← 탭 → 증권사 선택 시트 (미선택=전체)
```

## UI 재구성 — `app/(tabs)/myPage.tsx` 알림 카드

### 1. 기존 큰 모달 → 2개 포커스드 시트로 분리
기존 `NotificationSettingModal.tsx`의 두 블록을 각각 독립 바텀시트로 추출(스타일·로직 재사용):
- **`TimePickerSheet.tsx`(신규)** — 휠 피커(오전/오후·시·분) + "완료". `convert12To24`/`convert24To12`(`utils/time.utils.ts`) 재사용. props: `visible, initialTime, onClose, onConfirm(time24)`.
- **`BrokerSelectSheet.tsx`(신규)** — 증권사 체크리스트 + "전체" + "완료". `useAllBrokers` 결과를 prop으로 주입(현행과 동일). 다중선택 유지. props: `visible, allBrokers, initialSelected, onClose, onConfirm(names[])`.
- `NotificationSettingModal.tsx` **제거**(두 시트로 대체), `index.ts`에서 export 교체.

### 2. "오늘 공모주 일정" 인라인 확장 (disclosure)
`notifyMorning` 토글 바로 아래, `notifyMorning === true`일 때만 들여쓰기로 2행 렌더:
- **알림 시각 행** — `오전 8:00`(= `convert24To12(alarmTime)` 표기) + chevron, 탭 → `TimePickerSheet` 오픈.
- **포함 종목 행** — SPAC / REITs 인라인 체크박스(기존 모달 체크박스 JSX 재사용), 탭 → **즉시 저장**.
- `notifyAll` OFF면 이 서브행들도 회색·비활성.

### 3. "필터 설정" 섹션
- 섹션 라벨 + **증권사 행** — `전체`(0개) 또는 `N개` 요약 + chevron, 탭 → `BrokerSelectSheet` 오픈.

### 4. 저장 모델 (전부 즉시, "적용" 제거)
- 5개 알림 토글 + SPAC/REITs 체크박스 + 전체 알림: 변경 즉시 `handleUpdateNotification({ ... })`.
- `TimePickerSheet` "완료" → `setAlarmTime(t)` + `handleUpdateNotification({ alarmTime: t })` + 닫기.
- `BrokerSelectSheet` "완료" → `setSelectedBrokers(names)` + `handleUpdateNotification({ broker: names.join(',') })` + 닫기(빈 배열=전체=`''`).

### 5. 비활성화
`notifyAll` OFF → "알림 종류"·"필터 설정"의 모든 행(토글·서브행·증권사) `opacity-50` + `disabled`(기존 상세 설정 행 패턴 재사용).

## 검증 (에뮬레이터 실행 중)
1. 마이페이지 → 알림 설정. 전체 알림 ON.
2. "오늘 공모주 일정" ON → 알림 시각·포함 종목 서브행 노출 / OFF → 숨김.
3. 알림 시각 탭 → 시간 시트 → 완료 → 요약 갱신 + `PUT` alarmTime 반영, 재진입 유지.
4. SPAC/REITs 체크 → 즉시 저장, 재진입 유지.
5. 증권사 행 탭 → 시트에서 다중 선택 → 완료 → "N개" 요약 + `PUT` broker 반영.
6. 전체 알림 OFF → 알림 종류·필터 전체 회색·비활성.
7. 다크모드 색상 정상, `npx tsc --noEmit` 에러 0.

## 주의
- SPAC/REITs를 "오늘 공모주 일정" 하위 "포함 종목"으로 배치(사용자 목업). 백엔드가 `spac`/`reits`를 전역 적용한다면 라벨 위치를 "필터 설정"으로 옮기는 것도 고려 — 단 필드/API는 불변.
- 프론트 전용. 백엔드 5필드 지원은 라운드트립으로 확인됨.
- 계획서 프로젝트 루트 사본(`알림설정_개별토글_계획.md`)은 실행 시 이 내용으로 동기화.
