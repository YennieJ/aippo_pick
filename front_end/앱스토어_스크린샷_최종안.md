## 슬로건
> **"내 증권사 공모주만 쏙, AI로 쉽게 — 아이뽀픽"**

## 경쟁사 분석 요약

| 앱 | 포지셔닝 / 핵심 무기 | 약점 |
|---|---|---|
| 38커뮤니케이션 | 비상장·장외 포털, 정보량 1위 | UI 구식, 모바일·개인화 약함 |
| 공모주 알리미 (4.6) | "모든 증권사를 한 번에" + 캘린더/스크랩 | 정보 나열형, AI·일지 없음 |
| 공모주일정(공모주달력) | 배정 주수 기록 + 알림 | 단순 알림앱 |
| 일육공 160 | "매력지수" 100점 + 자동투자 일임 | 투자일임=진입장벽↑, 점수가 블랙박스 |
| 피너츠 공모주 | 실시간 경쟁률·락업해제 등 상세 데이터 | 정보형, 개인화 약함 |

### 아이뽀픽이 이기는 3개의 빈 자리
1. **"모든 증권사" vs "내 증권사"** — 경쟁사는 전부 보여주지만 아이뽀픽은 *내 증권사로 청약 가능한 것만* 골라줌. 앱 제목(`증권사 필터`)과 일치하는 유일 차별점.
2. **일육공 "매력지수"(블랙박스) vs 아이뽀픽 "AI 웹툰"** — 점수 + 이유를 웹툰으로 쉽게. "쉽다 + 광고 한 번이면 하루 종일 무료"로 우위.
3. **매매일지·수익률 추적** — 경쟁사 누구도 제대로 안 하는 영역 독점.

> 캘린더·알림은 모두가 가진 기본기 → 중반 배치. 앞 2컷에서 차별점을 폭발시킨다.

| # | 화면 | 메인 카피 | 서브 카피 |
|---|------|----------|----------|
| **1** | 홈 + 증권사 필터 | **내 증권사로<br>청약 가능한 공모주만** | 키움·삼성·미래에셋…<br>내 계좌로 되는 것만 쏙쏙 |
| **2** | AI 웹툰 리포트 | **AI가 웹툰으로<br>쉽게 풀어주는 분석** | 투자포인트·리스크·AI 점수까지<br>**광고 한 번이면 하루 종일 무료** |
| **3** | 증권사 순위 | **수익률 높은 증권사,<br>데이터로 비교** | 평균 수익률·상장 건수 순위<br>최근 1년 기준 |
| **4** | 캘린더 + 알림 | **청약일·환급일<br>알림으로 놓치지 않게** | D-Day 알림 · 스펙/리츠 필터 |
| **5** | 매매일지 | **공모주 수익,<br>자동으로 기록·정산** | 월별·연도별 손익을 한눈에 |
| **6** | 위젯 + 즐겨찾기 | **홈 화면 위젯으로<br>열지 않아도 확인** | 즐겨찾기·최근 본 공모주까지 |

> **App Store 3컷 노출 대비:** 1·2·3컷만으로 "내 증권사 필터 + 하루 종일 무료 AI + 데이터 비교" 완결 — 경쟁사가 동시에 못 가진 조합.

## 디자인 가이드
- 메인 카피 **7~12자 2줄**, 상단 배치 · 하단에 디바이스 목업
- **2컷 "하루 종일 무료" 배지**, **3컷 "1위 / 평균 수익률 %"** 숫자 강조 → 클릭 유발
- **다크모드 목업 + 실제 종목명** 노출로 금융앱 신뢰감
- 마지막 컷 하단 면책: *"제공 정보는 참고용이며 투자 판단의 책임은 이용자에게 있습니다."*
